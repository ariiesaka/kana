# triage labels

| Label in Matt Pocock skills | Label in our tracker | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer needs to evaluate this issue |
| needs-info | needs-info | Waiting on the reporter for more information |
| ready-for-agent | ready-for-agent | Fully specified, ready for an agent to implement |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be actioned |

Status records triage routing, not implementation progress. Remove it when work is accepted and track implementation in Work. For an issue, ready-for-human means a human must implement it; when triaging a pull request, it means the pull request is ready for human review or merge.
