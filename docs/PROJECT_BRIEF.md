# Project brief

## Goal

Help a complete beginner become comfortable reading hiragana and katakana fluently.

## Audience

The first user is the project owner. The interface should also be approachable for other beginners and present well as a portfolio project.

## Design preference

- Dark mode is the preferred default theme.

## Learning scope

- Reading recognition only. Speaking practice and handwriting are out of scope.
- The user's available study time changes from day to day, so practice should be easy to start and stop.
- Planned activities are multiple choice, matching kana with romaji, and flashcards, ordered from more guidance to recall.
- Start without accounts. Saving progress, streaks, and login are long-term goals.

## Initial direction

- Preferred visual direction: Quiet Reader, in dark mode.
- Design the study home screen first.
- Keep the study home screen minimalist and compact.
- Use lowercase for visible interface copy.
- Use the compact activity list as the home-screen composition.
- The first choice is a practice format: Multiple Choice, Matching, or Flashcards, ordered from more guidance to recall.
- Design each activity flow later.

## Deployment idea

A future deployment may use kana.ariiesaka.dev.
